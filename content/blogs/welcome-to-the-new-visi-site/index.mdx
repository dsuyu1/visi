The old site was a set of static pages that we updated once a semester. This one is built around posts, so recaps, notes, and writeups can go up the week they happen instead of waiting for a redesign.

*This post is placeholder copy while we move the real content over.*

## What lives here now

Everything we publish is a post with a tag on it. Workshop recaps are tagged `workshops`, competition writeups are tagged `ctf`, and anything about the club itself is tagged `club`. The tag chips at the top of any category page let you jump between them, and `/categories/all` lists every post we have.

## What we plan to publish

A few things we want to be consistent about:

- A short recap after every workshop, with the slides and any commands we ran.
- Writeups from CTFs, including the challenges we did not finish.
- Notes from talks and conferences members attend around the Valley.
- Practical guides — home labs, certification paths, internship applications.

## Help us fill it in

If you ran a session or solved something interesting, write it up. A few hundred words and a screenshot is enough. Officers can get you the details on how to submit a draft, and we will help edit it before it goes out.
